# VORA

파일을 넣고 필요한 작업을 누르면 결과를 저장하는 Windows 이미지·영상 앱입니다.

## [VORA 0.3.15 릴리스](https://github.com/noodle0845/vora-releases/releases/tag/v0.3.15)

**Windows 10/11 · 64비트 · 약 373MB**

릴리스 페이지의 Assets(첨부 파일)에서 `VORA_0.3.15_x64-setup.exe` 파일을 받은 뒤 실행하세요.

- 이미지: AI 업스케일, 배경 제거, 일괄 용량 최적화
- 영상: 다운로드, 프레임 추출, AI 업스케일, 용량 최적화
- 화이트·다크 테마, 붙여넣기, 프리셋, 작업 간 결과 연결

**0.3.14 이하를 사용 중이라면 새 업데이트 서명 키 적용을 위해 0.3.15 이상 설치 EXE를 한 번 직접 실행하세요.** 이후 버전은 앱에서 업데이트할 수 있습니다.

설치한 VORA는 새 버전을 자동으로 확인하고 업데이트를 안내합니다.

<details>
<summary>다른 첨부 파일 안내</summary>

설치할 때는 릴리스 페이지의 EXE 파일 하나만 받으면 됩니다. Releases의 업데이트 정보·서명·검증 파일은 별도로 다운로드하지 않아도 됩니다.

GitHub가 자동으로 표시하는 Source code 압축 파일에는 이 공개 저장소의 안내 문서만 들어 있습니다. 앱 소스는 비공개 저장소에서 관리합니다.

FFmpeg/FFprobe의 대응 소스와 오프라인 빌드 방법은 설치 폴더의 `licenses/FFmpeg-corresponding-source.tar.xz`에 함께 제공합니다. VORA 설정의 앱 정보에서 라이선스 폴더를 열 수 있습니다.
